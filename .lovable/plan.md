# Sudha Setu website reproduction

## Goal
Recreate all six supplied desktop screens as an interactive Sudha Setu website, using the uploaded background, exact palette, typography, wording, glass effects, and screen hierarchy.

## Build
- Establish the supplied design system: Deep Botanical Green `#1B4D3E`, Ayurvedic Gold `#D4AF37`, Healing Sage `#7FD8A4`, Deep Green Black `#0D1E17`; EB Garamond headings and Plus Jakarta Sans body/labels.
- Build shared brand, glass-panel, chat bubble, search/filter, icon, and input controls.
- Implement distinct navigable states for Voice Consultation, Hospitals, Diseases & Symptoms, and Charak Vaani chat; preserve both refined voice compositions as referenced states where relevant.
- Use the supplied background image as the site background and the supplied slide artwork for hospital imagery/icons where available.
- Add the shown interactions: navigation, voice/listening toggle, language selection, chat input/send, hospital search/city filter/details, disease search/category filter, and disease expand/collapse.
- Adapt the exact desktop compositions for tablet and mobile without simply scaling the interface.

## Validation
- Compare each implemented state against its matching slide at desktop size.
- Check 1440, 1280, 1024, 768, 480, and 375 widths for clipping, overlap, hierarchy, and readability.
- Verify interactions, metadata, and preview health before completion.
